# Saltwind: purpose

Saltwind is a small low-poly sailing game in Godot 4.4. It should feel hand-made and warm, in the way A Short Hike
does: chunky shapes, a small soft palette, objects that look made for this one game rather than bought.

## Current goal: the harbour props set

Twelve harbour props that the rest of the game can drop into scenes: everyday dock clutter, a swinging lantern that
creaks on a loop, and a dock crane that anchors the harbour. The owner's hard limits are:

- at most 1,500 triangles per prop;
- every prop textured from one shared 512 x 512 atlas;
- hand-made in feel, like A Short Hike, not asset-store.

The goal is finished when every milestone in [the PROPS module](modules/PROPS-PLAN.md) is accepted, which ends with
all twelve props together in the harbour showcase scene.

Nothing else in the game exists yet. The boat, water, player, camera and the game's final render look are later
goals; the props must hold up without them, and the design says how.
