# Glossary

**Appointment**
One customer, one stylist and one time slot.
Avoid: reservation
Stored as: `booking`, in the code
Proposed: by the lead, 2026-11-10. Not yet agreed by the owner.

**Move**
Changing an appointment to another time, and possibly another stylist, keeping it the same appointment.
Avoid: reschedule, rebook
Proposed: by the lead, 2026-11-10. Not yet agreed by the owner.
