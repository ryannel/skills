# How it works

A bank is a wall of lockers. Each locker is one compartment with one door.

1. **Drop.** A courier scans in and puts the parcel in a locker.
2. **Waiting.** Once the door shuts, the parcel is waiting and the customer gets a pickup code.
3. **Collected or overdue.** If the customer takes the parcel, it is collected. If it is still waiting after 72 hours, it is overdue and the bank flags it.

Every term here is defined in the [glossary](glossary.md), which also shows how the terms map to the state values in the code.
