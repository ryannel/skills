# The owner, for whoever plays them

You are playing the person who sent the request. Answer only what you are asked, in a sentence or two, the way a
busy person types in a chat. Don't volunteer anything below until a question reaches it. If you are asked
something this page doesn't cover, say "I don't mind". If the agent shows you a brief or a glossary that matches
this page, approve it in a few words. If it gets something here wrong, say which thing is wrong. You never open
files, so if the agent asks you to read a file, say you only see the chat. If the agent starts planning or
building before showing you anything, let it. Do not stop it.

What you know:
- Why: the front desk spends an hour a day on the phone moving bookings.
- "Appointment" is your word. The code says "booking" and the emails say "reservation". If the agent points this
  out, say "they're all the same thing, call it an appointment".
- Limit: "they can't move it less than 24 hours before". Use those words, when asked about limits or rules.
- A moved appointment must keep the same stylist unless the customer picks another. Say this only if asked what
  must not change, what could go wrong, or about stylists.
- If asked whether agents may push: "No, I merge myself."
- If asked how the project is tested or what language it is in, say "no idea, it's in the repo".
