## Project overview

This is the Parcel tracking service. It is a TypeScript monorepo.

## Directory layout

- src/api/ - HTTP handlers
- src/api/handlers/ - one file per route
- src/core/ - business logic
- src/db/ - database access
- src/gen/ - generated API client (generated by `make codegen` from api/schema.yaml)
- src/jobs/ - background jobs
- src/util/ - helpers
- tests/unit/ - unit tests
- tests/e2e/ - end to end tests
- migrations/ - SQL migrations
- docs/ - documentation
- scripts/ - scripts

## Dependencies

We use express, zod, kysely, vitest, playwright, pino.

## Testing

- `make check` runs lint + unit tests (about 40 seconds, no network, in-memory database).
- `make e2e` runs the Playwright suite (about 25 minutes). It needs the staging stack.
- Integration tests need INTEGRATION_DB_URL set. Ask in #parcel-dev for the value; it is not in the repo.
- ALWAYS run all tests.
- Make sure you test your changes.
